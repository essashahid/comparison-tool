3. Version comparison (latest vs previous)

The two most recent uploads (by save time) are compared automatically. HTS entries are matched by normalized_path (heading hierarchy), then classified as added, removed, or modified. Each distinct change creates a Pending sync task (deduped per version pair): Create new entry (added), Update existing entry (modified, with before/after text), or removal tasks with optional reason — all included in Download diff JSON. Use the tabs to show one change type, the search field to find an HTS code or path, and the side-by-side Before / After view for modified text (word-level highlights where text differs).
